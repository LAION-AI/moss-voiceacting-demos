MOSS-TTS Voice-Acting — DramaBox reinterpretation demos

Reference-guided reinterpretation of DramaBox clips on moss-tts-local-transformer-4.55b-voice-acting-v2: the original clip is fed back as a voice reference together with its own GENERAL/SCRIPT prompt, and the model regenerates the same line as a batched group of 8 candidates, reward-ranked by emotional similarity × inverse WER.

🎭 Reinterpretations — reference-guided best-of-8
All 133 clips, original + top-3 candidates, with a selection-strategy analysis (top2-of-4 vs top3-of-8). Reference and target say the same (correctly aligned) text.
🎚️ Dynamic emotion+VoiceNet LoRA merge vs. baseline
The long clips reinterpreted two ways side by side: plain v2 baseline vs. v2 with a dynamic mix of emotion + VoiceNet LoRAs merged in RAM (strengths read off the input clip), best-of-8 each.
🎙️ Reinterpretation v2 — emotion-only merge, best-of-64, new reward
Larger groups (n=64), emotion-only LoRA merge (budget 150%, no VoiceNet), reward = genuineness+blend+1.25·emo-sim × inverse-WER, natural full-length stopping.
🐾 Extended character voices — warm-started LoRAs (small classes)
Voices for smaller classes, warm-started from the most similar existing LoRA.
🎭 Emotion scenes — text-only, no reference (EN/DE)
